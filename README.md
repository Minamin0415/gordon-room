# ゴードンの部屋

スマートフォン向けの、小さな個人用電子ペットです。アカウント、サーバー、外部APIは不要です。データは使っている端末のブラウザ内に保存されます。数時間でお世話のきっかけが生まれますが、数日開かなくてもゴードンは死なず、状態は安全な上限・下限で止まります。

## 1. PCで動作確認する

ファイルを直接ダブルクリックして開くと、オフライン機能が正しく動きません。次のどちらかの方法で、このフォルダをローカルのWebサーバーとして開いてください。

### WindowsでNode.jsが入っている場合

`start-windows.cmd` をダブルクリックしてください。ブラウザが開きます。開かない場合は `http://localhost:8000/` を入力します。終了するときは、開いた黒い画面を閉じます。

### Pythonが入っている場合

1. この `gordon-pet` フォルダでターミナルを開きます。
2. `py -m http.server 8000` を実行します（`py` が使えない場合は `python -m http.server 8000`）。
3. PCのブラウザで `http://localhost:8000/` を開きます。

### MacなどでNode.jsが入っている場合

1. この `gordon-pet` フォルダでターミナルを開きます。
2. `node preview.cjs` を実行します。追加のパッケージは不要です。
3. `http://localhost:8000/` をPCのブラウザで開きます。

ゴードンを数回タップし、「飯」「あそぶ」「ガジェット」「なでる」「休ませる」を試してください。ガジェットを渡したらページを閉じ、開き直して「所持中」が残ることも確認できます。

**待機行動の動作確認:** URLを `http://localhost:8000/?debug=1` にすると、行動の終了から約3〜6秒で次の動作が始まります。最初の一周は見回し・歩き・あくび・尻尾などを決まった順番で表示するので、各動作を確認できます。部屋の右上には `idle: hat · hat 2/4 · gordon-hat.png` のように行動名、姿勢名、段階番号、画像名が出ます。ブラウザの開発者ツールのConsoleにも開始・終了時刻を記録します。特定の動作だけ見たい場合は `?debug=1&action=trunkTinker` のように `action=` へ行動名を指定してください。所持中の道具なら `action=radio_tune` も使えます。通常の `http://localhost:8000/` に戻すとデバッグ表示は消え、間隔は15〜35秒になります。小動作は12〜25秒を目安に入り、大きな尻尾は機嫌の良い時や食事・遊びの後に限られます。

確認モードのガジェット欄には、所持済みの道具を「戻す」ボタンも出ます。動作確認のために一時的に渡した物を片付ける用途です。通常モードでは従来どおり「所持中」と表示されます。

以前の画面が出る場合は、PCのローカルサーバーが起動しているか確認し、オンラインでページを再読み込みしてください。オフライン中は端末に保存された前の版を表示する場合があります。新しい版のService Workerが入ると、画面が自動で一度更新されます。

## 2. GitHub Pages のプロジェクトサイトで公開する

このフォルダはそのまま静的サイトとして公開できます。リポジトリ名が `gordon-room` ならURLは `https://あなたのGitHub名.github.io/gordon-room/` です。名前が違っても、画像・manifest・オフライン機能はそのURLに合わせて動きます。公開用の `.nojekyll` も入っています。

1. GitHubで新しいリポジトリを作ります。名前は自由です（例：`gordon-room`）。
2. **`gordon-pet` フォルダの中身**をリポジトリの一番上へアップロードします。配布用の `gordon-pet-pages.zip` を使う場合も、まず展開して中身をアップロードしてください。`index.html` と `.nojekyll` がリポジトリの一番上に見え、`assets` フォルダも同じ階層にある状態にします。ZIPファイルだけ、または外側の `gordon-pet` フォルダだけを置いても公開できません。既存リポジトリを使うなら、同じ中身を `docs` フォルダへ置く方法もあります。
3. リポジトリの **Settings → Pages → Build and deployment** で、**Source: Deploy from a branch** を選びます。ブランチはアップロードしたブランチ（通常 `main`）、フォルダは一番上に置いた場合 **`/(root)`**、`docs` に置いた場合 **`/docs`** を選んで保存します。
4. Pagesの画面に公開URLが出たら、末尾にリポジトリ名が付いたURLを開きます。反映には少し時間がかかる場合があります。最初はオンラインで一度開き、次に再読み込みしてオフライン用ファイルを端末に保存してください。
5. AndroidのChromeで同じHTTPSのURLを開き、次の「ホーム画面に追加する」手順へ進みます。

GitHub Pagesの公開URLは他の人からも開けます。ゴードンの状態や所持品は各端末のブラウザ内に保存され、リポジトリには送られません。`localhost` で遊んだ記録は、公開URLでは別の保存先になるため自動では移りません。公開時に変更するたび、`sw.js` のキャッシュ版番号を上げると古い画像やコードが更新されます。

公式手順：[公開元の設定](https://docs.github.com/ja/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)・[サイトの作成](https://docs.github.com/ja/pages/getting-started-with-github-pages/creating-a-github-pages-site)。

## 3. Androidスマホで開く

GitHub Pagesで公開したHTTPSのURLをAndroidのChromeで開いてください。HTML、CSS、JavaScriptと画像だけなので、サーバーのプログラムやログイン機能は要りません。

PCとスマホが同じWi-Fiにある場合は、PCのローカルサーバーを一時的な確認にも使えます。ただし、スマホからの `http://PCのIPアドレス:8000/` は通常PWAのインストールやオフライン機能の対象になりません。完成版として使うときはHTTPSのURLにしてください。

## 4. ホーム画面に追加する

1. AndroidのChromeでHTTPSのアプリURLを開きます。
2. 右上の「︙」を押します。
3. 「ホーム画面に追加」または「アプリをインストール」を選びます。
4. 追加後、一度オンラインで開いてください。必要なファイルが端末に保存され、以後は基本操作をオフラインで使えます。

オフラインでのデータも同じ端末に保存されます。ブラウザのサイトデータを削除すると、このアプリの記録も消えます。

## 5. キャラクター画像を差し替える

`assets/gordon/` に14枚の透過PNGがあります。`gordon-walk.png` は小さく歩く姿、`gordon-work.png` は座って手元をいじる姿です。`gordon-radio.png`、`gordon-caliper.png`、`gordon-label-maker.png` は、それぞれ道具を手に持って使う専用の姿です。ほかに待機、帽子直し、尻尾、見回し、腕組み、飯、なでる、座る、寝る画像があります。**同じファイル名で置き換える**だけで使えます。すべて1226×1283の透明キャンバスに置いてあり、下端を揃えると大きさや位置がぶれません。ファイル名を変えたい場合は `sprites.js` の一覧を編集してください。画像を変更したら `sw.js` の `CACHE_NAME` の末尾番号を1つ上げてください。これで既に使っている端末にも新画像が配信されます。

部屋・持ち物一覧・コマンドの道具は `assets/gadgets/room-*.svg` の3枚です。家具になじむ、丸みのある塗りのイラストです。使用中は `assets/gordon/` の「ゴードン＋道具」のドット絵に切り替わります。この2系統は別々に差し替えられます。以前の道具単体PNGは予備素材として残していますが、画面では使いません。

`sprites.js` には今後の専用差分のため、`yawn`（あくび）、`happy`（喜ぶ）、`sad`（しょんぼり）、`surprised`（驚く）、`called`（呼ばれて反応）という姿勢名も用意しています。現在は既存画像を使っています。新しい絵を作ったら、その姿勢の `src` を新画像へ変えるだけで、利用する行動すべてに反映されます。追加した画像のパスは `sw.js` の保存一覧にも足してください。

ホーム画面用アイコンは `assets/icons/` にあります。アイコンも変えたい場合は `icon-192.png` と `icon-512.png` をそれぞれ同じ大きさのPNGで置き換えます。

## 6. 台詞を追加する

`dialogue.js` を開き、追加したい場面の角括弧 `[...]` 内に `'新しい台詞'` をカンマ区切りで足してください。例：

```js
tap: ['何だ？', 'どうした。', '……何見てんだ。', '用があるなら言え。'],
```

保存したらページを再読み込みします。公開済みのアプリなら、画像と同様に `sw.js` の `CACHE_NAME` を更新してください。

## 7. ゴードンの自発行動を増やす

`behaviors.js` に行動の一覧があります。何も操作しない間、行動の終了から15〜35秒空けて一つを選びます。通常待機中は12〜25秒を目安に、瞬き・視線・肩の小さな動き・帽子を触る動作のいずれかが入ります。大きな生活動作や操作の後は、この小動作も間を空けます。普段は約1pxの呼吸と短い瞬きだけです。直前と同じ行動は選ばず、その前の行動も選ばれにくくしています。タップ、お世話、遊びやガジェット画面を開く操作でその場で中断し、待機時間を数え直します。画面を閉じている間は行動しません。

現在の基本行動は、帽子を直す、周囲を見る、こちらを見る、尻尾を動かす、少し歩く、腕組み、あくび、木箱をいじる、腹を気にする、座る、うとうとする、眠る、の12種類です。疲れるとあくびや座る動きが、機嫌が下がると腕組みが、退屈すると歩く動きが増えます。長く空腹なら腹を気にします。所持中のガジェットを使う行動も候補に混ざります。大きく尻尾を動かす行動は、機嫌が75以上の時か、食事・カード遊びの後2分間だけ候補になります。小動作の種類と間隔は同じファイルの `MICRO_MOTIONS` と `nextMicroDelay` で調整できます。

新しい行動を足すには、`behaviors.js` の既存の1項目（たとえば `hat`）をコピーして、`id`（重複しない名前）、`frames`（`sprites.js` の姿勢名を表示順に並べたもの）、`durationMs`（合計表示時間、1000で1秒）、`caption`（部屋の下の短い文字）、`when`（発生条件）、`weight`（出やすさ）、`returnsTo`（終了後の状態）を変更します。`frames: ['idle', 'hat', 'hat', 'idle']` のように同じ画像を繰り返すと、その画像を長めに見せられます。段階ごとに時間・小物・エフェクトを変えるなら、ガジェット行動のように `steps` を使います。新画像を使う場合は `assets/gordon/` に置いて `sprites.js` にも追加してください。動きまで変えたい場合は `styles.css` の `data-ambient` に同じ `id` のアニメーションを追加します。最後に `sw.js` に新画像を追加し、`CACHE_NAME` の番号を上げます。

深夜は、その夜の睡眠抽選に当たった場合、90秒以上操作がなければ行動の合間に「座る→うとうと→寝る」と進みます。操作するとこの進行は最初に戻ります。

## 8. あそび、食べ物、ガジェットを増やす

「あそぶ」を押すと HIGH & LOW が始まります。今のカードを見て「HIGH」か「LOW」を選びます。同じ数字は出ません。「もう一回」で続け、「×」で部屋へ戻れます。勝敗に応じてゴードンの台詞と表情が変わります。ゲームの種類・ルール・台詞は `games.js` にまとめています。新しい遊びを足すときは `GAMES` に定義を追加し、画面側の表示方法を `app.js` に追加します。勝敗記録は保存しません。

「飯」は今までどおり一押しで使えます。食べ物の種類は `foods.js` にあります。ここへ二種類目を追加すると、「飯」を押したときに選択肢が出ます。各食べ物の名前、説明、空腹と機嫌の変化、台詞の種類、使う画像を指定できます。おやつもこの一覧に追加してください。

「ガジェット」から小型ラジオ、デジタルノギス、古いラベルライターを各一つ渡せます。渡した物は部屋に小さな柔らかいイラストとして現れ、ブラウザ内に保存されます。所持中の物だけ、その後のランダム生活行動の候補になります。道具を使うときは「近づく→座って取る→使う→反応する→戻す」を、ゴードンが道具を持った専用画像で見せます。翌日など12時間以上あけて開いた場合、通常と同じ15〜35秒ほどで最初の自発行動が始まり、所持品を使う動きになります。ただし深夜の睡眠進行中は眠る動きを優先します。その後は通常どおり15〜35秒間隔で生活動作と小物の動作が混ざります。

新しいガジェットは `gadgets.js` の `GADGETS` に一項目追加します。既存の項目をコピーし、`id`（重複しない名前）、`name`、`description`、`image`（部屋・一覧用の柔らかい小物画像）、`usePose`（ゴードンが持った姿勢名）、`acquireDialogue`、`ownedDialogue`、`roomDecoration`（部屋での位置）、`usableIdleActions`（使うときの姿勢・時間・短い動作名・出やすさ・反応台詞）を書き換えます。`useSteps` を使えば、近づくところから戻るところまでの共通の流れを使えます。画面の一覧、所持表示、部屋の小物、自発行動への接続は自動です。新しい画像を使う場合は `sprites.js` と `sw.js` の保存対象にも追加してください。公開済みアプリを更新したら `sw.js` の `CACHE_NAME` の番号を上げます。

## 9. 部屋やボタンの見た目を変える

操作ボタンの皿・手・月・カードは `index.html` 内の塗りのある小さなイラスト、ガジェットボタンは部屋と同じ柔らかいラジオの絵です。丸い本体・厚みのあるボタン・クリーム色の吹き出し・4つの小メーターで、小さな玩具の見た目にしています。部屋の額、スタンドライト、木箱とマグ、ラグは `styles.css` の `.room-set` 付近にまとまっています。色を変えるときは同じファイルの `:root` にあるクリーム・金・水色・ラベンダーの色から調整できます。外部の画像配信やWebフォントは使っていないため、オフラインでも同じ見た目になります。公開済みの見た目を更新したら `sw.js` の `CACHE_NAME` の番号を上げてください。

## 10. ポーズの大きさと位置を調整する

すべてのポーズは `styles.css` の `.gordon-figure` という共通の表示枠（縦横比1226:1283）に収め、画像の下端を基準にしています。飯・なでる・座る・寝姿の微調整は、同じファイルの `.room[data-pose="feed"]` などにある `--pose-scale`（倍率）、`--pose-x`（左右）、`--pose-y`（上下）を変えてください。寝姿は横に広がりますが、全身を拡大せずラグに向けて下げています。飯は一瞬座ってから食べ、休むときは座ってから横になります。飯の皿や寝るときのクッションも `styles.css` の `.meal-setting` と `.rug-cushion` で調整できます。

## 操作と仕様

- ゴードン本体をタップすると返事をします。12秒以内に続けて触ると、段階的に嫌がります。
- 待機中はごく小さい呼吸と瞬きをします。タップ・連打・飯・なでる・休みでは専用の絵と表情に切り替わり、小さな吹き出しやエフェクトも出ます。端末で動きを減らす設定にしている場合は、アニメーションを抑えます。
- 「飯」は空腹度を下げ、「なでる」は機嫌と慣れ度を少し上げます。「休ませる」は疲れているときに元気を回復し、しばらく休みます。
- おなか・元気・機嫌・興味は数時間で少しずつ変わります。低い状態が2時間続くと、ほかの状態や動作・タップ時の台詞にも少し影響します。放置による不可逆な失敗はありません。
- 「あそぶ」は小さなカード勝負です。「ガジェット」で渡した道具は所持品となり、その後ゴードンが気まぐれに使います。
- 深夜は端末の時刻で23時〜翌4時59分です。同じ夜には一定の確率で寝ます。
- 状態・回数・最終アクセス時刻はブラウザ内に保存されます。データが壊れていた場合は安全な初期状態に戻します。
- 「データを初期化」は確認画面が出ます。実行すると元には戻せません。

## ファイル

| ファイル | 役割 |
| --- | --- |
| `index.html` / `styles.css` | 画面と見た目 |
| `app.js` | 操作と画面更新 |
| `state.js` | 状態、時間経過、保存 |
| `time.js` | 朝・昼・夜・深夜の判定 |
| `dialogue.js` | 編集しやすい台詞一覧 |
| `sprites.js` | ポーズ画像の一覧と説明文 |
| `behaviors.js` / `gadgets.js` | 自発行動とガジェットの種類・条件・出やすさ |
| `games.js` / `foods.js` | ミニゲームと食べ物のデータ |
| `manifest.webmanifest` / `sw.js` / `.nojekyll` | ホーム画面追加、オフライン対応、Pagesでの公開 |
| `assets/gordon/` | ゴードンの画像 |
| `assets/gadgets/` | `room-*.svg` は部屋・一覧の小物。PNGは予備素材 |
| `assets/icons/` | ホーム画面用アイコン |
| `preview.cjs` / `start-windows.cmd` | PCだけで試すための起動補助 |

14枚の人物画像と予備の道具PNGは、添付されたSDキャラクターシートと既存の待機画像を参照し、透過ドット絵として制作したものです。部屋・一覧用には別途3枚の柔らかいSVGイラストを用意しています。絵を差し替えても操作や保存の仕組みは変わりません。
